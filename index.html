Getting started

From template to working extension.

Use the repository template, replace the placeholder identity first, then build your feature on the dedicated extension entry point.

  1. 1
    Create and rename

    Replace the package, manifest, constants, URLs, and icon with your extension identity.

  2. 2
    Verify the identitypnpm run check:identity
  3. 3
    Run locallypnpm run dev

    Add http://localhost:5173/manifest-local.json to Owlbear Rodeo.

  4. 4
    Build and shippnpm run typecheck && pnpm test && pnpm run build
